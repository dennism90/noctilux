# NOCTILUX

Self-contained WebGL light-figure studio.

Open `NOCTILUX.html` in a modern browser with hardware acceleration.

## Features in this build
- Procedural particle forms (75)
- Media: Licht, Nebel, Wasser, Feuer, Lava, Dunkle Materie, Glas
- Geometric patterns: Kaleidoskop, Hexagon, Mandala, Tunnel, Stern, Blume
- Line drawing + trail, color mix, symmetry
- Zoom-pulse (music-coupled)
- Quantum motifs with dedicated point clouds (Qubits, Phase, Kopplung, Messung)
- Wild Random mode
- Adaptive quality and background pause

## Notes
- Single-file HTML, no external dependencies
- Desktop packaging prepared separately (Electron)
- This branch is prepared for review before merging to main

## Browser support
Works on Chrome, Edge, Firefox, Safari (desktop and mobile) with WebGL enabled.
