# NOCTILUX

Self-contained WebGL1 Light Figure Studio – procedural particle forms with advanced media, shaders, patterns and music reaction.

## Features (v0.8 – 2026-11-09)

- 75+ procedural forms
- Media: Licht, Nebel, Wasser, Feuer, Lava, Dunkle Materie, Glas/Glassplitter
- Shader styles and geometric patterns (Kaleidoskop, Hexagon, Mandala, Tunnel, Stern, Blume)
- Line drawing (Schweif), colorful particle mixes, symmetry
- Zoom-Pulse with music coupling (bass/highs/melody)
- Quantum motives with dense point clouds (Qubits, Phase, Coupling, Measurement)
- Wild Random mode (continuous random shifting of controls, shaders, media and forms)
- Adaptive quality, background pause, mobile/Fernsicht support

Open `index.html` (or `NOCTILUX.html`) in a modern browser with WebGL and hardware acceleration enabled.

Works on MacBook Pro (Safari/Chrome), Android (Chrome), Windows (Chrome/Edge/Firefox).

Self-contained: no external dependencies beyond the browser.
